Troubleshooting & FAQ

Common setup issues, and what they actually mean.

Prices aren't loading / it says "No API Key"

Connect a MarketData.app key in Settings → Market Data Connection. The free tier gives 100 requests/day — enough for a small portfolio, but if you're tracking many positions and hitting the limit, a paid tier raises it. Raw position tracking still works without a key — you just won't get live prices, Greeks, or IV until it's connected. (Separately, the decision engine itself also needs an active trial or license — see below.)

Health Score, Smart Action, scanners, or Cloud Sync are locked

Your trial or license has ended. Your raw position tracking (ticker, strike, expiration, entry/current price, basic P&L) stays fully available regardless — only the decision engine (Health Score, Smart Action, eject prices, capital efficiency), the Find Puts / Scan CCs scanners, Weekly Review, and Cloud Sync pause. Activate a license in Settings → License to restore them immediately, no reload needed.

CSV import isn't working / trades look wrong

The importer currently reads Fidelity's exact export format only. If you're on a different broker, or an Excel file (.xlsx/.xls) rather than CSV, it won't parse correctly — use manual entry instead (see Core Workflows).

My PC and phone show different positions

Check Settings → Cloud Sync — you need the same GitHub token and Gist ID entered on both devices, and either Auto-sync on or a manual Push/Pull to move data between them. Also check the version badge next to the DeltaCortex logo on each device; if they differ, update the older one first. No Cloud Sync set up? A Local Backup download/restore (Settings → Local Backup) moves data across manually.

Setting up on a new device or browser

Two options: turn on Cloud Sync and pull on the new device, or download a Local Backup JSON file on the old one and restore it on the new one. Either brings over positions, closed trades, earnings/dividend dates, sector map, portfolio config, and your API key.

Still stuck?

If none of the above covers it, email deltacortexhq@gmail.com — include what you were trying to do, what happened instead, and your app version (shown next to the DeltaCortex logo).
